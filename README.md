## Alex Kurkar

CS student at the University of Nottingham.

**Projects**

- [InvariantLab](https://github.com/akurkar07/InvariantLab) — a benchmark for whether AI coding agents write numerically correct physics code. Seeded bugs pass ordinary unit tests but fail conservation checks; seven verification layers (independent oracles, convergence checks, metamorphic relations) catch them. 258 agent repair attempts across three models, published as a null result. Python, CI, MIT.
- [OrderBook](https://github.com/akurkar07/OrderBook) — a price-time priority matching engine in C++: red-black tree of price levels with per-level FIFO queues, differential-tested against a naive reference over seeded random sequences. Benchmarks in the README.
- [Neural-Network](https://github.com/akurkar07/Neural-Network) — a neural network from scratch in NumPy with a CuPy/CUDA backend, and the benchmarks showing where the GPU wins and where kernel-launch overhead makes it lose.
- [Interpreter](https://github.com/akurkar07/Interpreter) — a Pascal interpreter and bytecode VM: parser and type checker in Python, a stack VM in Python, and a native VM in C.
- Penny (Reinvent the Wheel, Oct 2026, team of three) — made Fiji/ImageJ conversational without changing its engine. My part: a macro editor that runs nothing until the user confirms, and end-to-end tests showing recorded analyses replay identically.

**Elsewhere**

- Project lead for an 8-person team building a bias-detection ML system for a recruiting consultancy.
- Competed for Nottingham at UKIEPC 2025. Nine hackathons in first year.
- Leaf Fellow, studying AI risk.
